# 关于本项目

本项目使用 MkDocs 生成技术文档，并通过 GitHub Pages 自动部署。

课程：开源软件设计与开发。实验主题：GitHub Actions 和 GitHub Pages 使用。

## 技术组成

| 工具 | 作用 |
| --- | --- |
| Markdown | 编写文档内容 |
| MkDocs | 构建静态文档 |
| Material | 提供导航、搜索与响应式主题 |
| GitHub Actions | 自动安装依赖、构建和发布 |
| GitHub Pages | 托管生成的网站 |

源文件保存在 main 分支，构建结果发布到 gh-pages 分支。
