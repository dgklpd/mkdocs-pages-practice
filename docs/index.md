# 欢迎使用 MkDocs

这是《开源软件设计与开发》实验二的技术文档网站，使用 **MkDocs** 构建，通过 **GitHub Actions** 自动部署到 **GitHub Pages**。

- [关于](about.md)：了解本项目和实验目标。
- [使用指南](guide.md)：查看本地预览与自动发布流程。
- [API 参考](api.md)：了解计算器示例的函数接口。

2. 将 Markdown 文档自动构建并发布为可访问的网站。
